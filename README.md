# Nuances & Nœuds

Bienvenue sur le projet **Nuances & Nœuds**, une boutique en ligne de créations au crochet.

## Aperçu

- Page unique avec tous les produits
- Choix couleur et parfum
- Panier fonctionnel
- Produit sur commande avec prix variable
- Sections À propos et Contact

## Utilisation

1. Ouvrir `index.html` dans un navigateur pour voir le site.
2. Ajouter des produits au panier et tester les options couleur/parfum.
